Signal Routing

Split the input into paths, then choose where each path lands.

auto-start

Three layers, as the engine has them

  • ① Input → paths: today's 2 × 2 matrix, once per path. Mono guitar into two paths is IN 1 on in both.
  • Paths: each one is a full Mixer chain (EQ, inserts, gate, level). Edit a chain in the Mixer: sidebar sub-entry or Open in Mixer.
  • ② Paths → outputs: per device, one row pair per path. Cells that meet on one channel add up. The sum block sets level, polarity and trim per path on that device.
  • Cards are starting points. Any edit afterwards shows Custom.

Latency

  • On each device, every path that plays there waits for the slowest one. Hatched = alignment delay.
  • Alignment is per device: in Per-device mixes the stream's limiter doesn't slow the headphones.
  • Muted and un-soloed paths still count, so unmuting never moves the latency.
  • Alignment off: red when unaligned paths add up on one channel (comb filter), amber when they only sit on different channels.

Edges

  • Duplicate copies the chain and its routing muted, so the sum never jumps +6 dB.
  • At most 4 paths. Each one costs its inserts' CPU; on PipeWire duplex all paths share one graph quantum.
  • Master level and mute (Mixer → Output) act after the sum, on every device.
  • Not here: more than two captured channels, sends between paths, a path that feeds another path.
