Signal Routing

Choose exactly where each channel lands.

auto-start

Two layers, as the engine has them

  • Input → Mix: today's matrix. Its columns said OUT 1/2, but they feed the chain, so they're renamed MIX L / MIX R. Channel mode and monitoring stay beside it.
  • Mix → Outputs: new. One small matrix per output device: Mix L/R rows × that device's channels. The chain runs once; this only picks which device channels play the result.
  • The stored 2×4 table's dead columns 3/4 go away; a device's extra channels become real columns.

Per device

  • Same device list and order as Mixer → Output. Selecting a device here or there selects the same one.
  • Presets cover the usual jobs: 1/2, 3/4, both pairs, mono to all, swap, clear. Cells handle the rest.
  • Unused channels: silent by default. Mono copy is today's behaviour (L/R average on extra channels), kept as an option.
  • Every change here is LIVE, crossfaded like today's route changes.

Edge cases

  • Same interface, second pair (headphones on Out 3/4) is a mapping on the clock device, not a second device: no extra clock, no cushion.
  • Nothing routed on a device: amber warning; it plays silence.
  • Missing device: its map is kept and greyed; it applies again when the device returns.
  • Meters are per device channel. Today there's one shared stereo meter; the engine would publish one per device.
  • Not here: per-channel gain, more than the two input channels picked on Live.
